# URL Keyword Crawler - Chrome拡張機能

ホームページ内をクローリングし、指定したキーワードを含むURLを全てリスト化するChrome拡張機能です。

## 機能

- 指定したURLを起点にサイト内のページを自動クローリング
- 指定キーワード（複数可）を含むページのURLをリスト化
- リスト化されたURLを全件コピー
- シンプルなUI
- 他の拡張機能に影響しない独立した設計

## インストール方法

### 開発者モードでのインストール

1. Google Chromeを開く
2. アドレスバーに `chrome://extensions/` と入力してEnter
3. 右上の「デベロッパーモード」をオンにする
4. 「パッケージ化されていない拡張機能を読み込む」をクリック
5. このフォルダ（`Google_Web-`）を選択
6. 拡張機能がインストールされる

## 使い方

1. クロールしたいサイトのページを開く（URLが自動入力される）
2. 拡張機能アイコンをクリックしてポップアップを開く
3. **クロール開始URL**: クロールを開始するURLを確認・編集
4. **検索キーワード**: 検索したいキーワードをスペース区切りで入力
   - 例: `カーボンフットプリント 温室効果ガス`
5. **最大クロール数**: クロールするページの上限（デフォルト: 100）
6. **最大深度**: リンクをたどる深さの上限（デフォルト: 3）
7. 「クロール開始」ボタンをクリック
8. マッチしたURLが順次表示される
9. 「全URLをコピー」ボタンで全件クリップボードにコピー

## 利用例

1. 環境省のホームページ（https://www.env.go.jp/）を開く
2. 拡張機能を起動
3. キーワードに「カーボンフットプリント」を入力
4. クロール開始
5. 結果のURLをコピー

## ファイル構成

```
Google_Web-/
├── manifest.json      # 拡張機能の設定
├── popup.html         # ポップアップUI
├── popup.js           # UIロジック
├── background.js      # クローリング処理（Service Worker）
└── icons/
    ├── icon16.png
    ├── icon48.png
    └── icon128.png
```

## 注意事項

- クロールはサイトに負荷をかける場合があります。最大クロール数は適切に設定してください
- 一部のサイトはCORSポリシーによりアクセスできない場合があります
- JavaScriptで動的に生成されるコンテンツはクロールできません（静的HTMLのみ対応）
